# Kit utils

Shared libraries copied to the **project repo root** via `core/scripts/seed-utils.sh` (or **`apply-module.sh kit-utils`** / legacy alias **`webapp-utils`**).

Includes logging (`neat_logger`, `neat_logger_ts`), Playwright helpers, coverage kit, ChatGPT extractors, and other cross-stack tooling — not web-only.

Do not edit copies under target repos; treat this tree as the kit source of truth.
