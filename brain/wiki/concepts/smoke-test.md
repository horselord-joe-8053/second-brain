# Smoke Test
A Smoke Test is a preliminary test conducted to check the basic functionality of a system or process. In the context of the Second Brain system, the smoke test verifies that Nashsu Source Watch can successfully pick up files from the specified directory and write the output to the wiki. This testing methodology is crucial for ensuring operational verification and system reliability.
