# Nashsu Source Watch
Nashsu Source Watch is an organization/tool responsible for monitoring and processing files from the `raw/sources/uploads/` directory and writing the output to the `wiki/`. It plays a central role in the functionality of the Second Brain system, ensuring that data ingestion and output generation occur smoothly.
