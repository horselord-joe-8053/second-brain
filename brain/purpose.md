# Second Brain — corpus purpose

Personal knowledge base compiled by **Nashsu LLM Wiki** from material under `raw/sources/`.

- **Harness (Hermes)** writes captures and manifests into `raw/sources/`; it does not edit compiled wiki pages directly.
- **Human UI:** Obsidian (or LLM Wiki) on compiled output under `wiki/`.
- **Project root for LLM Wiki:** this `brain/` directory.

See [PLAN_SECOND_BRAIN_HERMES_V1.md](../docs_manual_gen/PLAN_SECOND_BRAIN_HERMES_V1.md).

## Language-learning and mixed-language sources

Spreadsheets and notes that mix English with another language (e.g. Portuguese verb tables with English glosses) should be ingested with **Settings → Output → Multilingual (preserve source languages)** so each passage stays in its source language. Keep conjugation grids, example sentences, and bilingual rows **verbatim** in the wiki summary; do not rely on chat “reingest” — use **Sources → Ingest** on the original file under `raw/sources/`.
