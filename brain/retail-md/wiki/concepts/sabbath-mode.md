# Sabbath Mode  
Sabbath mode is a feature found in some appliances, including the GE GNE27JYMFS refrigerator and the KitchenAid KRFF507HPS refrigerator, that allows them to operate in compliance with Jewish Sabbath laws. This mode typically limits certain functions to ensure that the appliance does not perform work that is prohibited during the Sabbath.

## Importance  
The Sabbath mode is crucial for users who observe these practices, as it allows them to use their appliances without violating religious laws. Instructions for activating this mode are provided in the user guide, ensuring users can easily enable it when needed.

## KitchenAid Specifics  
In the KitchenAid KRFF507HPS refrigerator, Sabbath Mode disables lights and dispensers to comply with Sabbath observance. This mode is significant for users who follow specific religious practices.
