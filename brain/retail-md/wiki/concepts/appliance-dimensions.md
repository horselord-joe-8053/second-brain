# Appliance Dimensions
Appliance dimensions refer to the specific measurements required for the installation of various refrigerator models. This concept is essential for ensuring that the refrigerator fits properly within the designated space. The user guide for the GE GNE27JYMFS emphasizes the importance of accurate measurements, particularly the width of the cabinet opening, which should accommodate a refrigerator width of 30"-36" (76.2 cm - 91.4 cm) depending on the model.
