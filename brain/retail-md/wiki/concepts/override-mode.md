# Override Mode
Override mode is a feature in the Samsung RF28K9070SG refrigerator that allows users to temporarily change the settings for ice production. This mode can be activated by pressing and holding the "Cubed Ice" button for 3 seconds. The instructions for using this feature are detailed in the user manual, emphasizing its importance for user control over the appliance.
