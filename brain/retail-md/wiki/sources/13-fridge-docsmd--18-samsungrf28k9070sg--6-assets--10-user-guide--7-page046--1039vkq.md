# Samsung RF28K9070SG User Manual - Page 046

This page of the user manual for the Samsung RF28K9070SG refrigerator provides details about the control panel, including temperature readings for the freezer and fridge compartments, indicators for various features, and instructions for checking the MAC address.

![The image displays a refrigerator control panel with two temperature readings: "Freezer: 88°F" and "Fridge: 89°F." Below the readings, there are indicators for "Door Alarm," "Ice Maker," and "Lighting." The panel includes buttons labeled "Freezer," "Fridge," and "Ice Water Off." Additionally, there is a note explaining how to check the MAC address, detailing a sequence of button presses and the expected display format for the MAC address. The text also mentions that the temperature panel will show "--- / --" for an unknown MAC address or if the Wi-Fi connection is lost.](../media/13-fridge-docsmd--18-samsungrf28k9070sg--6-assets--10-user-guide--7-page046--1039vkq/001-page_046.png)
