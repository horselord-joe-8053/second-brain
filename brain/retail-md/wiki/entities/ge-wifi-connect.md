# GE WiFi Connect
GE WiFi Connect is a product feature that allows certain GE refrigerator models to connect to the internet via the GE ConnectPlus module, enhancing smart appliance capabilities. This feature is central to the functionality of the refrigerator and relates to modern appliance connectivity.
