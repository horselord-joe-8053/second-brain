# Retail-md — LLM Wiki project

Brain-profile **`retail-md`**: same retail domain intent as `brain/retail`, tuned for markdown/text sources and a clean wiki tree (no dependency on the prior retail ingest cache).

## Goal

Build a searchable wiki from `raw/sources/` via LLM Wiki ingest.

## Scope

**In scope:** fridge manual text/markdown under `raw/sources/`.

**Out of scope:** copying `brain/retail/.llm-wiki` cache or Postgres ticket corpora (wire those separately if needed).
