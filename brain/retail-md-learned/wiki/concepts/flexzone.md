# FlexZone

FlexZone is a customizable compartment within the Samsung RF28K9070SG refrigerator that can be set to different temperatures for various food types. This feature enhances the refrigerator's versatility in food storage.

## Modes
The FlexZone can be adjusted to several modes, including:
- **Freezer:** Same temperature as the freezer compartment.
- **Soft Freezing:** Ideal for meat and fish.
- **Chill / Meat:** Suitable for deli items.
- **Cool:** Designed for beverages.
