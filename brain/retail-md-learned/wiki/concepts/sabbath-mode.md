# Sabbath Mode

Sabbath Mode is a feature available on some GE refrigerator models that disables certain functions, such as temperature control interactions and advanced features like the door alarm, to accommodate religious observance. This mode is designed to ensure that the refrigerator operates in a way that aligns with specific religious practices.
