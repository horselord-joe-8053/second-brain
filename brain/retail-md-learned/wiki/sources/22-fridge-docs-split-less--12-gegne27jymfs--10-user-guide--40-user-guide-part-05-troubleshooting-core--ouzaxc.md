## Troubleshooting Guide Overview

This document provides a comprehensive troubleshooting guide for GE / GE Profile bottom-freezer refrigerators, specifically the GNE27JYMFS model. It outlines common symptoms, possible causes, and recommended checks or actions to resolve issues.

## Common Symptoms and Solutions

### GE-SYMPTOM-001 — Refrigerator Does Not Operate
- **Possible Causes:**
  - Refrigerator in defrost cycle. 
    - **Action:** Wait about 30 minutes for defrost cycle to end.
  - Controls set to OFF.
    - **Action:** Set the controls to a lower temperature setting.
  - Refrigerator is unplugged.
    - **Action:** Push the plug completely into the outlet.
  - Blown fuse or tripped circuit breaker.
    - **Action:** Replace fuse or reset the breaker.
  - Refrigerator in showroom mode.
    - **Action:** Unplug the refrigerator and plug it back in.

### GE-SYMPTOM-002 — Vibration or Rattling
- **Possible Cause:** Leveling legs need adjusting.
  - **Action:** See Level the refrigerator.

### GE-SYMPTOM-003 — Motor Operates for Long Periods
- **Possible Causes:**
  - Normal when refrigerator is first plugged in.
    - **Action:** Wait 24 hours for the refrigerator to completely cool down.
  - Large amounts of food placed in refrigerator.
    - **Action:** This is normal.
  - Door left open.
    - **Action:** Check to see if package is holding door open.
  - Hot weather or frequent door openings.
    - **Action:** This is normal.
  - Temperature controls set at the coldest setting.
    - **Action:** See Controls section.

### GE-SYMPTOM-004 — Refrigerator or Freezer Compartment Too Warm
- **Possible Causes:**
  - Temperature control not set cold enough.
    - **Action:** See Controls section.
  - Warm weather or frequent door openings.
    - **Action:** Set the temperature control one step colder.
  - Door left open.
    - **Action:** Check to see if package is holding door open.

### GE-SYMPTOM-005 — Frost or Ice Crystals on Frozen Food
- **Possible Causes:**
  - Door left open.
    - **Action:** Check to see if package is holding door open.
  - Too frequent or too long door openings.
    - **Action:** This is normal.

### GE-SYMPTOM-007 — Automatic Icemaker Does Not Work
- **Possible Causes:**
  - Icemaker switch is in the OFF position.
    - **Action:** Set the switch to the ON position.
  - Water supply turned off or not connected.
    - **Action:** See Installing the Water Line section.
  - Freezer compartment too warm.
    - **Action:** Wait 24 hours for the refrigerator to completely cool down.

### GE-SYMPTOM-016 — Water Dispenser Does Not Work
- **Possible Causes:**
  - Water supply line turned off or not connected.
    - **Action:** See Installing the water line section.
  - Water filter clogged.
    - **Action:** Replace filter cartridge or remove filter and install plug.
  - Air may be trapped in the water system.
    - **Action:** Press the dispenser arm for at least two minutes.
  - Dispenser is LOCKED.
    - **Action:** Press and hold the LOCK pad for 3 seconds.

## Conclusion

This troubleshooting guide serves as a valuable resource for diagnosing and resolving common issues with GE / GE Profile bottom-freezer refrigerators, ensuring optimal performance and customer satisfaction.
