## Troubleshooting Guide for KitchenAid French Door Bottom Mount Refrigerator

This document serves as a comprehensive troubleshooting guide for the KitchenAid French Door Bottom Mount Refrigerator, detailing various symptoms, possible causes, and solutions.

### KA-SYMPTOM-001 — The refrigerator will not operate

**Knowledge ID:** `KA-SYMPTOM-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** KitchenAid French Door Bottom Mount Refrigerator models to which guide W11218735B applies; features marked “on some models” require inspection of fitted options  
**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 33.  
**Customer symptom:** The refrigerator will not operate.

**Possible causes:**
- Check electrical supply
- Check controls
- New installation
- Refrigerator control is in Showroom mode (on some models)

**Documented checks / solutions:**
- Plug the power cord into a grounded 3 prong outlet. Do not use an extension cord.
- Make sure there is power to the outlet. Plug in a lamp to see if the outlet is working.
- Reset a tripped circuit breaker. Replace any blown fuses.
- Ensure the controls are turned on. See “Using the Controls.”
- Allow 24 hours following installation for the refrigerator to cool completely.
- If the refrigerator is in Showroom mode, cooling is turned off and “Showroom” will be illuminated on the control panel.

### KA-SYMPTOM-002 — The motor seems to run too much

**Knowledge ID:** `KA-SYMPTOM-002`  
**Evidence:** [DOCUMENTED]  
**Applies to:** KitchenAid French Door Bottom Mount Refrigerator models to which guide W11218735B applies; features marked “on some models” require inspection of fitted options  
**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 34.  
**Customer symptom:** The motor seems to run too much.

**Possible causes:**
- High efficiency compressor and fans
- Hot room or outdoor temperature
- Large amount of warm food added
- Door(s) opened too frequently or for too long
- Refrigerator control is set too cold
- Door or drawer gasket is dirty, worn, or cracked

**Documented checks / solutions:**
- Larger, more efficient refrigerators run longer at lower, more energy efficient speeds.
- It is normal for the refrigerator to work longer under these conditions.
- For optimum performance, place the refrigerator in an indoor, temperature controlled environment.
- Warm food will cause the refrigerator to run longer until the air cools to the desired temperature.
- Open the door less often and ensure the refrigerator is level.
- Clean or change the gasket.

### KA-SYMPTOM-003 — The lights do not work

**Knowledge ID:** `KA-SYMPTOM-003`  
**Evidence:** [DOCUMENTED]  
**Applies to:** KitchenAid French Door Bottom Mount Refrigerator models to which guide W11218735B applies; features marked “on some models” require inspection of fitted options  
**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 34.  
**Customer symptom:** The lights do not work.

**Possible causes:**
- LED lighting does not need to be replaced
- Dispenser light is set to OFF
- Doors have been open longer than 10 minutes

**Documented checks / solutions:**
- If there is power to the refrigerator and the lights do not illuminate when a door or drawer is opened, call for service.
- On some models, the dispenser light will operate only when a dispenser paddle is pressed.
- Close the doors and drawer to reset, and open to resume lighted task.

### KA-SYMPTOM-004 — Shelves with under-shelf LEDs do not light up (on some models)

**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 34.  
**Customer symptom:** Shelves with under-shelf LEDs do not light up (on some models).

**Possible causes:**
- Shelf hooks are not fully engaged in shelf supports
- Shelf supports are loose
- Doors have been open longer than 10 minutes

**Documented checks / solutions:**
- Check that the rear shelf hooks are completely seated into the slots in the shelf supports.
- Check all shelf support screws to ensure they are fully tightened.
- Close the doors and drawer to reset, and open to resume lighted task.

### KA-SYMPTOM-005 — Pantry Temperature Control not lit/unresponsive

**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 34.  
**Customer symptom:** Pantry Temperature Control not lit/unresponsive.

**Possible causes:**
- Refrigerator is in Cooling Off mode
- Control initialization process did not complete successfully

**Documented checks / solutions:**
- Exit Cooling Off mode.
- Unplug the refrigerator, wait 5 seconds, then plug it back in and wait 30 seconds before opening any doors.
