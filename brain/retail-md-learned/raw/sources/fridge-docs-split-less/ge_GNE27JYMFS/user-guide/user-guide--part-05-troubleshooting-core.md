### GE-SYMPTOM-001 — Refrigerator does not operate

**Knowledge ID:** `GE-SYMPTOM-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** GE / GE Profile bottom-freezer refrigerators of 18, 19, 21, 22, 24, 25, 26 and 27 cu ft in publication 49-1000472 Rev. 9; specific model families and fitted controls must be checked separately  
**Source:** Refrigerators — Bottom Freezer: Owner’s Manual & Installation Instructions, PDF page(s) 45.  
**Customer phrasing:** Refrigerator does not operate; GE refrigerator refrigerator does not operate.  

**Customer symptom:** Refrigerator does not operate.

**Documented cause/check pairs from the manual:**
- **Possible cause:** Refrigerator in defrost cycle.  **Documented check/action:** Wait about 30 minutes for defrost cycle to end.
- **Possible cause:** Either or both controls set to OFF.  **Documented check/action:** Set the controls to a lower temperature setting.
- **Possible cause:** Refrigerator is unplugged.  **Documented check/action:** Push the plug completely into the outlet.
- **Possible cause:** The fuse is blown/circuit breaker is tripped.  **Documented check/action:** Replace fuse or reset the breaker.
- **Possible cause:** Refrigerator is in showroom mode.  **Documented check/action:** Unplug the refrigerator and plug it back in.

**Expected result/limits:** Perform relevant customer-safe checks first. A listed possible cause is not an established diagnosis; if a cause/action line has unreadable font content, use the printed original table before giving unsafe instructions.
