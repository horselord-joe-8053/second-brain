### SAM-FREEZER-001 — Freezer setting and Power Freeze

**Knowledge ID:** `SAM-FREEZER-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** the Samsung free-standing refrigerator configurations and optional features illustrated in this edition; this document does not print an exhaustive model-suffix compatibility list on the cover  
**Source:** Refrigerator — User manual (Free Standing Appliance), PDF page(s) 37.  
**Customer phrasing:** What temperature range can I set?; How to turn off Power Freeze?; Prepare to freeze a large batch of food.  

**Set temperature:** Press **Freezer** repeatedly to select a freezer temperature from **5°F (−15°C) to −8°F (−23°C)**.

**Power Freeze:** Hold Freezer for **3 seconds** to activate; hold again for 3 seconds to deactivate. It runs the freezer at full power for several hours, then returns to the prior setting. For freezing large quantities, the manual says to activate at least **20 hours in advance**. It increases power consumption; turn it off if not needed.

### SAM-FRIDGE-001 — Fridge temperature and Power Cool

**Knowledge ID:** `SAM-FRIDGE-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** the Samsung free-standing refrigerator configurations and optional features illustrated in this edition; this document does not print an exhaustive model-suffix compatibility list on the cover  
**Source:** Refrigerator — User manual (Free Standing Appliance), PDF page(s) 37, 38.  
**Customer phrasing:** How do I make the fridge colder?; Power Cool feature; Fridge keeps running at full power.  

**Set temperature:** Press **Fridge** repeatedly; selectable values are **34–44°F (1–7°C)**.

**Power Cool:** Hold Fridge for **3 seconds** to activate or deactivate. It temporarily runs cooling at full power for rapid cooling or after a door has been left open, then resumes previous settings. The manual warns of higher energy consumption while active.

### SAM-FLEXZONE-001 — FlexZone four modes and food-selection limits

**Knowledge ID:** `SAM-FLEXZONE-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** the Samsung free-standing refrigerator configurations and optional features illustrated in this edition; this document does not print an exhaustive model-suffix compatibility list on the cover  
**Source:** Refrigerator — User manual (Free Standing Appliance), PDF page(s) 39.  
**Customer phrasing:** Can I use FlexZone as freezer?; FlexZone temperature options; Meat stored in FlexZone Cool.  

**How to select:** Hold **FlexZone** for **3 seconds**, then press repeatedly to cycle modes; release when the correct mode appears.

| Mode | Documented setting | Intended use in the manual |
|---|---|---|
| Freezer | Same as freezer compartment | Frozen food |
| Soft Freezing | **23°F (−5°C)** | Meat and fish for extended freshness |
| Chill / Meat | **30°F (−1°C)** | Deli items, fish, bacon, cheese |
| Cool | **41°F (5°C)** | Beverages to be used fairly quickly |

**Caution:** The manual warns not to store meat or food needing colder storage in the **Cool** setting; changes can release moisture from food/meat. If FlexZone cannot be selected, unlock Control Lock first.

### SAM-DOOR-ALARM-001 — Door alarm and Celsius/Fahrenheit switching

**Knowledge ID:** `SAM-DOOR-ALARM-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** the Samsung free-standing refrigerator configurations and optional features illustrated in this edition; this document does not print an exhaustive model-suffix compatibility list on the cover  
**Source:** Refrigerator — User manual (Free Standing Appliance), PDF page(s) 38.  
**Customer phrasing:** How to change F to C?; Door-open alarm sounds; Stop door alarm.  

**Door alarm:** Press **Door Alarm** to enable or disable. When enabled, a door left open for **more than two minutes** triggers an audible alarm and blinking indicator. The alarm is enabled by factory default.

**Temperature unit:** Hold **Door Alarm for 3 seconds** to switch between Celsius and Fahrenheit.

**Control Lock:** Hold **Control Lock** for **3 seconds** to lock, and repeat to unlock. ### SAM-CLEANING-001 — Cleaning, electrical precautions and allowed surfaces

**Knowledge ID:** `SAM-CLEANING-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** the Samsung free-standing refrigerator configurations and optional features illustrated in this edition; this document does not print an exhaustive model-suffix compatibility list on the cover  
**Source:** Refrigerator — User manual (Free Standing Appliance), PDF page(s) 59.  
**Customer phrasing:** How to clean the fridge safely?; Can I spray cleaner into the dispenser?.  

**Documented safe cleaning:** Unplug the power cord, use a **moistened soft lint-free cloth or paper towel** for interior/exterior and dry with a clean cloth before reconnecting. Regularly clear dust/water from plug terminals with a dry cloth.

**Do not:** Spray water directly onto the refrigerator, put objects into dispenser openings or use benzene, thinner or strong automotive/home detergents such as Clorox™ on the surface. The manual identifies surface damage, fire and shock risks.
