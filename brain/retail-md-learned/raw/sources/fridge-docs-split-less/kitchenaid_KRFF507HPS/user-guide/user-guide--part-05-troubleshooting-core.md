### KA-SYMPTOM-001 — The refrigerator will not operate

**Knowledge ID:** `KA-SYMPTOM-001`  
**Evidence:** [DOCUMENTED]  
**Applies to:** KitchenAid French Door Bottom Mount Refrigerator models to which guide W11218735B applies; features marked “on some models” require inspection of fitted options  
**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 33.  
**Customer phrasing:** The refrigerator will not operate; How to troubleshoot the refrigerator will not operate.  

**Customer symptom:** The refrigerator will not operate.

**Possible causes recorded in the manual:** Check electrical supply Check controls New installation Refrigerator control is in Showroom mode (on some models)

**Documented checks / solutions:** Plug the power cord into a grounded 3 prong outlet. Do not use an extension cord. Make sure there is power to the outlet. Plug in a lamp to see if the outlet is working. Reset a tripped circuit breaker. Replace any blown fuses. NOTE: If problems continue, contact an electrician. Make sure the controls are turned on. See “Using the Controls.” Allow 24 hours following installation for the refrigerator to cool completely. NOTE: Adjusting the temperature controls to the coldest setting will not cool either compartment more quickly. If the refrigerator is in Showroom mode, cooling is turned off and “Showroom” will be illuminated on the control panel. See “Using the Controls” for more information.

**Applicability and answerability:** A listed cause is not a confirmed diagnosis. These are the issue-specific manufacturer troubleshooting rows; if a source table continues across pages, check the referenced printed page and model options before acting.

### KA-SYMPTOM-002 — The motor seems to run too much

**Knowledge ID:** `KA-SYMPTOM-002`  
**Evidence:** [DOCUMENTED]  
**Applies to:** KitchenAid French Door Bottom Mount Refrigerator models to which guide W11218735B applies; features marked “on some models” require inspection of fitted options  
**Source:** French Door Bottom Mount Refrigerator — Use & Care Guide, PDF page(s) 34.  
**Customer phrasing:** The motor seems to run too much; How to troubleshoot the motor seems to run too much.  

**Customer symptom:** The motor seems to run too much.

**Possible causes recorded in the manual:** High efficiency compressor and fans The room or outdoor temperature is hot. A large amount of warm food has been recently added. The door(s) are opened too frequently or for too long. The refrigerator door or freezer drawer is ajar. The refrigerator control is set too cold. The door or drawer gasket is dirty, worn, or cracked.

**Documented checks / solutions:** Larger, more efficient refrigerators run longer at lower, more energy efficient speeds. It is normal for the refrigerator to work longer under these conditions. For optimum performance, place the refrigerator in an indoor, temperature controlled environment. See “Location Requirements.” Warm food will cause the refrigerator to run longer until the air cools to the desired temperature. Warm air entering the refrigerator causes it to run more. Open the door less often. Make sure the refrigerator is level. See “Door Closing and Door Alignment.” Keep food and containers from blocking the door. Adjust the refrigerator control to a less cold setting until the refrigerator temperature is as desired. Clean or change the gasket. Leaks in the door seal will cause the refrigerator to run longer in order to maintain desired temperatures.

**Applicability and answerability:** A listed cause is not a confirmed diagnosis. These are the issue-specific manufacturer troubleshooting rows; if a source table continues across pages, check the referenced printed page and model options before acting.
