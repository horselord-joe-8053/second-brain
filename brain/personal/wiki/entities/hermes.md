# Hermes
Hermes is a desktop application that provides web search and scraping capabilities. It operates as a managed platform, simplifying user interaction with backend services and infrastructure. The application integrates various tools, such as `web_search` and `web_extract`, allowing users to perform searches and data extraction without needing to manage complex backend configurations.

## Key Features
- **Managed Platform:** Hermes abstracts the complexity of credential management and API cost accounting, providing a seamless user experience.
- **Bundled Backend Infrastructure:** It aggregates demand and subsidizes costs through agreements with service providers like Nous Research.
- **Hybrid Execution Model:** Hermes intelligently decides between local and cloud execution for tasks, optimizing performance and reducing costs.
- **Tiered Resource Allocation:** The platform manages API usage through free tiers and caching strategies to minimize operational costs for users.

## Future Developments
Hermes is expected to transition to support user-managed authentication, allowing users to connect their own API keys for higher-volume usage and premium features.
