# Tiered Resource Allocation
Tiered resource allocation is a strategy for managing API usage and costs through free tiers and caching. This concept is integral to understanding how Hermes minimizes operational costs for users.

## Key Aspects
- **Free Tiers:** Tools are configured to utilize generous free tier allocations from backend providers before accessing paid quotas.
- **Caching:** Common search queries and frequently visited pages are cached to prevent redundant API calls, further optimizing cost management.
