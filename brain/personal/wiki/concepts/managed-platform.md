# Managed Platform
A managed platform is a system that abstracts complexity from users, managing backend services and infrastructure. This concept is central to understanding how Hermes simplifies user interaction with web search tools.

## Importance
Managed platforms like Hermes provide a frictionless user experience by hiding the complexities of credential management, API cost accounting, and infrastructure maintenance. Users can focus on their tasks without worrying about the underlying technical details.
